# Bigriyo - Professional Repair Center

**Bigriyo** (बिग्रियो) is a modern web application built for Kathmandu's leading multi-device professional repair center.

---

## Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Icons:** [Lucide React](https://lucide.dev/)

---

## 🚦 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18.0 or later) installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SRIYOGconsulting/bigriyo.app.git
   cd bigriyo.app
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Run Dev Server:**
   ```bash
   npm run dev
   ```
